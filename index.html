Slop editor

Try it on your own slop Install

Flip the Slop-o-meter, then read this

# in Claude Code
/plugin marketplace add baphaelman/slop-editor
/plugin install slop-editor@slop-editor

npx slop-editor install page.html
npx slop-editor edit page.html

<!-- in the page -->
<p data-slop="intro.p1"></p>
// in the block
"intro": { "p1": ["The agent wrote this. ", { "me": "I wrote this." }] }

# the AI's words (the default)
npx slop-editor install --auto src
# words you wrote yourself
npx slop-editor install --auto --author me src
